# RykoCollection Android

A separate Android WebView wrapper for https://rykocollection.vercel.app/.

- Does not modify the website source, Vercel deployment, or Supabase project.
- Loads the live website; web updates appear automatically.
- Requires internet access.
- Package: com.rykocollection.app
- Minimum Android: 6.0 (API 23)
- Build with JDK 17 and Gradle 8.9.
