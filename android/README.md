# RykoCollection Android (Kotlin)

A separate Kotlin Android WebView app for https://rykocollection.vercel.app/.

- The Android app source is Kotlin.
- Does not modify the website source, Vercel deployment, or Supabase project.
- Loads the live website; website updates appear automatically.
- Requires internet access.
- Package: com.rykocollection.app
- Minimum Android: 6.0 (API 23)
- Build with JDK 17 and Gradle 8.9.
- APK output: app/build/outputs/apk/debug/app-debug.apk
